# דף נחיתה דו-מגדרי — צוף · השער THE GATE

**תאריך:** 2026-06-06
**מקור:** הקלטת קול של צוף (06/06/2026) — שתי התלבטויות: לוגו קבוע + הנגשת הדף גם לגברים.
**החלטה (ישי):** אתר אחד, דף נחיתה אחד, פנייה לשני המגדרים, מקסימום נגישות.

## הבעיה
כל הקופי באתר נכתב בלשון נקבה ופונה לאישה ("את ממשיכה", "שלחי", "לכל אישה"). צוף מטפלת גם
בגברים (עבודה רגשית, ללא מגע, מרחוק/בזום), וגבר שנוחת על הדף מרגיש "לא בשבילי".

## הגישה — כלל הזהב
מפרידים בין שני קולות:
1. **קול צוף על עצמה (גוף ראשון)** — נשאר נשי ואותנטי: "אני מאמינה", "אני צוף", "תפקידי", "הייתי אומרת".
2. **הפנייה אל המבקר (גוף שני)** — הופכת לניטרלית, בלי "את/ה" מסורבל, דרך:
   - ניסוח נומינלי/אימפרסונלי ("כלפי חוץ הכל ממשיך", "אפשר להניח את המשקל")
   - כינויים שכבר ניטרליים בעברית (בך, בתוכך, עצמך, לך, עבורך)
   - "לכל מי ש..." + זכר-כללי מכליל ("לכל מי שמרגיש תקוע")
   - ציווי/פנייה ברבים לכפתורי פעולה ("שלחו", "דברו", "חייגו", "השאירו")

## שינויים מרכזיים (index.html)
- Hero (נשאר): "יש בתוכך חיים שלמים שמחכים להיפתח" — כבר ניטרלי.
- Pain: "את ממשיכה לתפקד" → "כלפי חוץ הכל ממשיך כרגיל".
- Transform: "מהמקום שבו את — אל המקום שאת רוצה" → "...שבו אתם — ...שאתם רוצים".
- About: "כל אישה נושאת בתוכה" → "כל אדם נושא בתוכו"; "שבו את יכולה להניח" → "שבו אפשר להניח".
- Testimonials: כותרת "מספרות"→"מספרים"; ציטוט אחד הפך לגברי (ייצוג גברי); הערה → "מטופלים ומטופלות".
- FAQ: "לכל אישה שמרגישה" → "לכל מי שמרגיש"; "מה שאת מביאה" → "מה שיש לך להביא"; "דברי איתי" → "אפשר לדבר איתי".
- CTAs/טופס: "שלחי/דברי/חייגי/השאירי/תרצי/מוזמנת" → רבים מכליל; "ואחזור אלייך" → "ואחזור אליכם".
